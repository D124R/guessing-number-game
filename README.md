# Guessing Number Game

A small number-guessing game with a graphical interface, built with Python and Tkinter.

## How to play

The computer chooses a secret number from 1 to 10. Enter your guess and the game will tell you whether to try a higher or lower number. Guess correctly to win, then click **Começar de novo** to play again.

## Requirements

- Python 3
- Tkinter (included with most standard Python installations)

## Run the game

Open a terminal in this folder and run:

```bash
python adivinhacao.py
```

On Windows, you can also run:

```powershell
py adivinhacao.py
```

## What this project practices

- Variables and random numbers
- User input and number conversion
- Conditions and functions
- Building a window with Tkinter
